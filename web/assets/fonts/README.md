# Fonts for server-side rendering

Static TTFs of the KAFRIADA NET type families, for images drawn on the server
(the WhatsApp share preview; later the printed card's PNG and PDF). Never sent
to browsers: pages load the same families through `next/font`.

| File | Family | License |
|---|---|---|
| FiraSansCondensed-ExtraBoldItalic.ttf | Fira Sans Condensed | SIL OFL 1.1 |
| Andika-Regular.ttf, Andika-Bold.ttf | Andika (SIL International) | SIL OFL 1.1 |
| GeistMono-Medium.ttf | Geist Mono | SIL OFL 1.1 |

Downloaded from Google Fonts, 2026-10-06.
